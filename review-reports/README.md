# 问题汇报 / Review Reports

独立于 `docs/` 的问题汇报目录。只放**审阅结论与阻断项**，不放设计文档、计划、测试用例说明——那些仍在 `docs/plans/`、`docs/reports/`。

## 收录标准

一份文件对应一次审阅，必须包含：

- 审阅对象（commit / 工作树状态）与基线
- 逐条问题，带严重级别（P0 阻断 / P1 提交前必修 / P2 可记录后修）
- **可复现的证据**：命令、输出、`file:line`
- 提交门禁清单及其当前状态

结论有变化时**追加新文件**，不覆盖旧文件——保留判断的演进轨迹。
