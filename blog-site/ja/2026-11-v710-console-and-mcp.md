# v7.1.0：Console の統一と MCP 設定の共通化

Console の既定画面が、承認済みのローカル AI ツール管理画面に変わりました。
ツール、MCP サービス、プロジェクトメモリ、活動履歴、設定を一つの画面構成で扱います。
旧サイドバーとページ実装は削除し、以前のブックマークは対応する現在の画面へ転送します。
再読み込みとブラウザーの戻る・進むにも対応しています。

新画面は引き続き、明示されたサンプルデータと模擬結果を使用します。実際の非公開
プロジェクトのメモリ読み取りや設定書き込みは未接続です。既存の API、CLI、設定、
メモリ、セッション保存領域は保持します。サンプルの表示は実際の接続成功を意味しません。

実際の MCP 設定管理は共通のプランナーと形式別ライターを使用します。一つのファイルの
編集をすべて計算してから一度のアトミックな書き込みを行い、管理外のバイトとクライアント別
フィールド規則を保持します。Browser、codemap、Pi、Headroom の登録がこの経路を再利用します。
内容が一致していても外部エントリーの所有権は自動取得せず、force でも明示的な引き継ぎを省略できません。

証拠収集ドライバーは既定ではプレビューのみです。明示的に実行した場合は、設定の読み戻し、
所有権、元のファイルハッシュへの復元を確認します。記録済みの18設定先は、検証済み12、
未検証1、現在のホストで非対応5です。過去の設定検証と現在の接続テストは別々に扱い、
利用できないクライアントを検証済みとは表示しません。

Console の型検査と本番ビルド、Shell テスト95件が成功しました。既定の一時環境での
最終回帰テストは成功2746、失敗0、スキップ12でした。ブラウザーでは画面遷移、メモリと
MCP のサンプル操作、モバイル表示を確認し、本番の書き込み要求はありませんでした。
Windows TUI の App モジュール参照も正しい同一ディレクトリのパスに修正しました。

このコミットは7.1.0のバージョン情報と文書を準備します。リリースタグの作成や、
インストール用パッケージの公開は行いません。
