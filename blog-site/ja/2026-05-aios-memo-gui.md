# aios memo GUI：Agent の記憶を生きたグラフとして可視化

あなたのコーディング Agent は数週間働き続けています。コードを書き、バグを修正し、決定を下してきました。しかし、その履歴は実際どのように見えるのでしょうか？

**今、それを見ることができます。**

aios memo GUI は ContextDB のビジュアルインターフェースです — Agent のセッション履歴をインタラクティブなノードグラフに変換し、何が、いつ、どのように繋がっているかを探索できます。

## 何を見ているか

上のスクリーンショットは、aios memo GUI の **ContextDB ビュー** を示しています。各部分の意味：

**グラフ（左側）：**
- 各**ノード**はプロジェクトの記憶の一部 — セッション、チェックポイント、ファイルへの参照
- **ノード間の線**は関係を示す：「このチェックポイントはあのセッションから生まれた」「このファイルはあのイベントで参照された」
- **紫色のノード**はプロジェクト内の実際のファイルへの参照

**詳細パネル（右側）：**
- 任意のノードをクリックして完全な詳細を表示
- 信頼スコアやリスクレベルなどのメトリクス
- 親セッションと証拠参照のリスト
- ソースファイルパスの表示

**トップバー：**
- クイック統計：ノード数、セッション数、チェックポイント数、リスク数
- フィルタータブ：すべて、セッション、チェックポイント、イベント、リスク
- 検索：名前で特定のノードを検索

## なぜこれが重要か

GUI が登場する前、Agent の履歴を理解するには次のような作業が必要でした：

- `memory/context-db/sessions/` のファイルを掘り下げる
- CLI コマンドを実行して JSON 出力を読む
- セッション、チェックポイント、イベントを頭の中で繋ぎ合わせる

**今は見るだけで済みます。**

先週の火曜日に Agent が何をしていたか知りたい？ セッションノードをクリック。特定のチェックポイントでどのファイルが触られたか確認したい？ エッジを辿る。フラグされたリスクを見つけたい？ リスクタブでフィルター。

## はじめに

aios memo GUI は既存の ContextDB データを読み取ります。RexCLI がセットアップされ、プロジェクトに `.contextdb-enable` がある場合、データは準備完了です。

1. GUI を開き、プロジェクトを指定
2. **Load** をクリックして ContextDB データをインポート
3. グラフを探索 — ノードをクリック、接続を辿る、検索を利用

グラフはプロジェクトの完全な記憶を読み込みます：セッション、チェックポイント、イベント、ファイル参照、リスクフラグ、ハンドオフ記録。ContextDB が記録したすべてが、一目で確認できます。

## できること

### セッションをまたぐバグの追跡

リスクノードをクリックし、エッジを辿って、そのリスクが最初に検出されたセッションとチェックポイントに戻る。問題が現れた時、Agent が正確に何をしていたか確認できます。

### 記憶の系統を理解

セッションがどう繋がっているか確認：どのチェックポイントが次のセッションを生成したか、どのファイルが複数のセッションで参照されたか、コンテキストが Agent 間でどう引き継がれたか。

### Agent の行動を監査

各ノードの信頼スコアとリスクレベルで素早く健全性をチェック。「リスク」でフィルターしてフラグ付きアイテムのみ表示、一つずつ調査。

### 特定のイベントを検索

検索バーでファイル名、セッション ID、任意のテキストコンテンツからノードを検索。JSONL ファイルを grep する必要はもうありません。

## より大きな絵

aios memo GUI は **ContextDB** エコシステムの一部です — コーディング Agent がセッションをまたいで記憶するためのシステム。ContextDB はバックグラウンドで自動的に動作し（イベントの記録、チェックポイントの作成、コンテキストパックの構築）、GUI はその様子を人間が読める形で提供します。

単に見栄えが良いだけでなく、実用的です。軌道を外れた Agent をデバッグする時、決定の理由を理解しようとする時、夜間のハーネス実行中に何が起きたかを監査する時、ビジュアルグラフはどのログファイルよりも速くストーリーを伝えます。

## 試してみる

RexCLI で ContextDB を既に有効にしている場合、データは準備できています。aios memo GUI を開いて探索を始めましょう。

RexCLI は初めてですか？ [クイックスタートガイド](https://cli.rexai.top/ja/getting-started/)から始めてプロジェクトで ContextDB を実行し、戻って Agent の記憶を可視化しましょう。
