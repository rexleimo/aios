# v5.10.0 — リリースの信頼性とリポジトリのスリム化

> 2026-09-06 · 新機能なし、「信頼性」に特化したリリース

## 主な変更

- **Windows 回帰スイートが完全グリーン**：2 つの慢性的な赤テストは CRLF の成果物にすぎませんでした。drift guard は行末正規化で比較し、`.gitattributes` が主要ソースを LF に固定するため、Windows と Linux CI が同じゲートを通過します。
- **リリース証拠ゲートの強化**：証拠ゲートをフルテストの前に移動（フェイルファスト）。`release-preflight.sh` はコミットされていない証拠があると通過を拒否します——証拠はタグ付けされたコミットに存在しなければなりません。
- **サプライチェーンの固定**：すべての GitHub Actions を完全なコミット SHA にピン留め。gitleaks シークレットスキャンジョブを追加。ルートと mcp-server に `npm audit --omit=dev --audit-level=critical` ゲート（基準：critical 0）。Windows スモークは `npm ci` に変更。
- **リポジトリのスリム化**：pptx node_modules 351 ファイルと `.cache/` フォント 110 ファイルを Git から削除。ルートの散在するデバッグログ 4 件を削除。認証成果物は gitignore ホワイトリスト化され、`git add -f` 不要に。
- **プロンプト執筆規範**：`docs/prompt-authoring-norms.md`——契約ファースト、意味判断はモデルの自己申告（ReAct 式）、ハードゲートは検証プロトコル。キーワード/正規表現による意図の推測を禁止。
- **ナラティブの統一**：AGENTS.md / mkdocs 4 言語 / README を「AIOS オーケストレーション制御プレーン」の位置づけに統一。ブラウザ MCP は legacy コンポーネントと明記。

## アップグレードノート

破壊的な動作変更はありません。CI は critical レベルの npm アドバイザリとシークレットスキャンで失敗します。Windows 開発者はプル後に再チェックアウトして行末を正規化してください。
