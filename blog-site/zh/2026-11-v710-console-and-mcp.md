# v7.1.0：统一 Console 界面与 MCP 配置写入

默认 Console 已切换为确认后的本机 AI 工具管理器。AI 工具、MCP 服务、项目记忆、
活动记录与设置使用同一套界面。旧侧栏和页面实现已删除，旧书签跳转到当前对应视图，
刷新和浏览器前进后退都能得到正确的视图。

新界面仍使用明确标注的示例数据和模拟结果。真实私人项目记忆读取与配置写入尚未
接入。已有 API、CLI、配置、记忆和会话存储继续保留；浏览示例不能证明私人项目
连接已经可用。

真实 MCP 配置管理采用共享规划器与格式写入器。一个文件的全部编辑先计算完毕，
再进行一次原子写入，保留非托管字节和各客户端字段规则。Browser、codemap、Pi
和 Headroom 注册复用该路径。归属仍需显式确认：内容匹配不会自动接管外部条目，
force 也不能绕过接管。

证据驱动器默认只预览，显式执行后检查配置读回、归属和原文件哈希恢复。已记录的
18 个落点中，12 个通过验证、1 个未验证、5 个当前主机不支持。历史落点证据与
当前连接测试分别记录，客户端不可用时不会冒充验证通过。

Console 类型检查和生产构建通过，Shell 测试 95 项通过。最终默认临时环境全量
回归记录为 2746 通过、0 失败、12 跳过。浏览器验证覆盖导航、记忆与 MCP 示例流程
以及移动布局，没有生产写请求。Windows TUI 的 App 模块引用也已改为正确的同目录路径。

本次提交准备 7.1.0 版本及其文档，不会自行创建发布标签或发布可安装的软件包。
