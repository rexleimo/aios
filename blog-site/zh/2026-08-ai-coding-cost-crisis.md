# AI 编程账单失控：Cursor 隐藏成本、亚马逊烧掉 180 万美元，本地层能改变什么

> **快速回答：** AI 编程账单失控有三个原因——花费不可见（Cursor 刚刚从用量页移除了成本数据）、没有预算护栏（亚马逊内部报告显示简单编码任务花掉 180 万美元，超预算 860%）、按 token 计费惩罚每一次冗余重试。本地 agent 层能直接修复前两个问题：它在每次 dispatch 事件里记录 token/美元成本、在运行跨过成本阈值时预警、把便宜任务路由给便宜模型，并把项目记忆留在本地磁盘，让你不再为重复发送的上下文反复付费。

## AI 编程成本成为热点的这一周

最近几天，三个故事让 AI 编程花费无法再被忽视：

1. **Cursor 从用量页和 CSV 导出中移除了成本信息。** 这个改动立刻被注意到——在 Hacker News 上拿到 300+ 点赞。当厂商让计量表变得不可读时，通常是因为数字本身不好看。
2. **亚马逊用 Claude 做简单编码任务花了 180 万美元，超预算 860%。** Tom's Hardware 曝光的内部用量报告显示，简单、可自动化任务的 API 花费远超所有预测。没人注意到，直到账单到来。
3. **Codex 恢复五小时用量限额。** 限额回归，是因为用量真的很贵。

这三件事不是孤例，而是同一失败模式在三个不同规模上的重演：**AI 编程花费不可见、没有上限，并且挂在每个 token 都在计费的计量表上。**

## 账单为什么会失控

### 1. 花费在设计中就是不可见的

大多数 AI 编程工具的计费入口和功能/席位管理在同一个界面。当数字变得不舒服，阻力最小的路径就是不再展示它。但你看不见的数字就没法优化。回答不了"这周 agent 每个任务花了多少钱"的团队，已经失去了对预算的控制。

### 2. Agent 行动、人类审批——没人盯着计量表

一个问题尝试五种方案，就要花五倍的钱。一次重构把同一个文件生成十遍，就为十次生成付费。没有遥测的自主性就是这样把 20 万美元的预算变成 180 万美元的：每一步单独看都合理，但没有一步会主动报价。

### 3. Token 计费惩罚冗余上下文

每次调用都会重新发送相关上下文。如果你的"记忆"只是一个每次调用都重新上传的巨大 prompt，你就在为同样的知识反复付费。控制成本的最大杠杆不是换更便宜的模型，而是**不重复发送你已经知道的东西。**

## 本地层能改变什么

AIOS 是一个本地优先的工作流层，运行在 Claude Code、Codex、Gemini CLI、OpenCode 和 Grok Build 之上。它不替换你的客户端，而是在周围补上缺失的可观测性和记忆。对应上面三个原因：

### 可见性：每次 dispatch 都带价格

每次派发的运行都会把归一化的 token 和美元成本（`inputTokens`、`outputTokens`、`totalTokens`、`usd`）写进事件记录。运行结束后你能看到某个工作项精确花了多少 token、多少钱，而不是等一个把所有东西混在一起的月度汇总。

### 护栏：在账单到来之前预警

dispatch 洞察层会把每次运行的 token 用量和可配置阈值比较。超过阈值时，你会收到 `cost.high` 警告和可操作的下一步（"review dispatch cost and consider smaller work-item batches"）——在运行还新鲜的时候，而不是计费周期结束之后。

### 路由：便宜任务走便宜模型

模型路由器按能力、**成本**和实测成功率派发。一行修复不需要旗舰模型，复杂的架构问题才需要。按成本路由，区别在于你的 agent 舰队是永远用最贵的工具，还是用能干活的最便宜的工具。

### 记忆：停止为同一份上下文付费

ContextDB 把项目记忆存在本地磁盘、做 token 压缩，每次调用只注入相关片段。配合社区 RTK/Caveman 压缩层，可以砍掉冗余上下文税——大多数 AI 编程预算里最大的一笔隐形开销。

## 快速上手

```bash
aios init --all
aios doctor --native --verbose
```

然后参考[模型路由器文档](https://cli.rexai.top/model-router/)为 dispatch 设置 token 预警阈值、把便宜任务路由给便宜模型，再读[Token 智能文档](https://cli.rexai.top/token-compression/)了解压缩保留什么、丢弃什么。

## FAQ

### 我的编码客户端不是已经显示用量了吗？

大多数客户端显示的是某种汇总用量，而 Cursor 刚刚证明了这种可见性可以随时被移除。你自己工作流层写入的事件级记录是你能控制的数据——厂商 UI 改动藏不掉它。

### 重点是花得更少，还是花得更聪明？

两者都要。阈值预警阻止失控运行，路由把便宜工作交给便宜模型，ContextDB 去掉冗余上下文。三者叠加，通常总 token 和总美元都会下降。

### 我需要停用现在的编码工具吗？

不需要。AIOS 兼容你正在用的客户端（Claude Code、Codex、Gemini CLI、OpenCode、Grok Build），它只是在周围增加可观测性和记忆层。

### 细节在哪里看？

[更新日志](https://cli.rexai.top/changelog/)按版本列出了成本相关改动，[架构文档](https://cli.rexai.top/architecture/)解释了 dispatch 事件、evidence 和成本在系统中如何流转。

计量表消失不是因为成本没问题，而是因为数字本身就是新闻——在你的数字被别人替你读出之前，确保它们自己可读。
