# Chrome Autostart Test Design

## Scope contract

- User goal: starting macOS or a coding agent must not launch Google Chrome unless the user explicitly requests browser/CDP use.
- In scope: the AIOS-managed macOS CDP launch agent generated by `scripts/lib/components/browser/cdp-service.mjs`, including cleanup of the already-installed `com.aios.cdp9222` service.
- Out of scope: changing explicit `browser_launch` behavior, removing browser MCP support, or changing user-owned Chrome login/profile data.
- Allowed test seam: exported CDP plist rendering and service lifecycle functions, exercised through the existing Node test suite with injected filesystem/process boundaries where needed.
- Completion: generated launch-agent configuration has no login/restart trigger; stopping the service removes AIOS-managed persistence; existing explicit CDP start remains available; the installed service is unloaded and its AIOS-managed plist is removed.

## Acceptance mapping

| Acceptance behavior | Observable assertion |
| --- | --- |
| macOS login does not open Chrome | Rendered plist does not enable `RunAtLoad`. |
| Closing Chrome does not cause AIOS to reopen it | Rendered plist does not enable `KeepAlive`. |
| Starting a coding agent does not indirectly revive the old CDP browser | Stopping the AIOS service unloads it and removes its managed plist so launchd cannot load it on a later login/session event. |
| Explicit CDP use remains supported | `cdp-start` still writes/loads the service and explicitly kickstarts it. |

## Minimal vertical slice

The stable public seam is `node scripts/aios.mjs internal browser cdp-start|cdp-stop`. The smallest representative slice tests the generated launchd policy and stop cleanup because those are the persistent OS-level triggers; MCP server startup itself only starts the Node server and contains no browser launch call.

Tests must not be made green by deleting assertions, skipping cases, weakening expected launchd policy, or asserting only that mocks were called without checking the generated/removed persistence artifact.
