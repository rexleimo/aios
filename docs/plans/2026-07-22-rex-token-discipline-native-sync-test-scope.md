## User Goal

`AIOS Token Discipline` section, so clients receive the same compact token
hygiene guidance and the public token-discipline regression test passes.

## Explicit Non-Goals

- Do not change Rex workflow outcomes, Provider selection, or standalone state.
- Do not change browser MCP configuration, token-profile policy values, or a
  user's unmanaged instruction text.
- Do not repair unrelated doctor warnings or global client installation drift.
