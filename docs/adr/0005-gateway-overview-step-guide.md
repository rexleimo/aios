# ADR 0005 — 网关总览：状态驱动步骤引导 + 页面瘦身

## 状态

Accepted（2026-11-17）。

## 背景与诉求

用户反馈网关总览"不能一眼就懂"、是"大杂烩"、页面偏长。原页面把运行状态、客户端接入、
历史日志、客户端×模型大表平铺，且每段都堆"不代表在线/不证明已验证"的免责声明。

## 决策

1. **状态驱动三步引导（加法）**：新增纯函数 `gateway-setup-guide.mjs` 派生
   ①启动网关 ②配置模型来源 ③接入客户端的 done/next/todo 与唯一"下一步"动作；
   `NEXT_ACTIONS` 映射让标签与派发共用单一事实源，消除重复 if 级联。
   引导 UI 抽成独立组件 `gateway-setup-guide.tsx`，`GatewayControl` 不再因引导而变化。
2. **语义修正**：步骤按依赖顺序（来源先于接入）；"已保存但未加载/缺凭据"指向配置模型来源，
   不再误导去接入客户端；stale 进程视为未运行。
3. **减法**：
   - 网关/接入面板删去重复的长篇免责声明，只保留状态徽章 + 主操作 + 一行结论。
   - 删除与引导重复的"已保存配置"独立面板。
   - `AgentOverview` 增加 `compact` 属性：网关总览用它把 3×4 客户端大表收成一行
     "最近请求涉及 N 个客户端 · 日志内 M 条"摘要 + "查看分配明细"入口；首页仍用完整版。
4. **布局不变量**：布局测试要求三个 deferred reads 解析期间零位移。引导横幅用固定
   min-height，删文本不改结构，保证状态切换不抖动。

## 权衡与被拒选项

- 拒绝给共享 `AgentOverview` 传复杂 mode 对象；一个布尔 `compact` 足够且诚实。
- 拒绝删掉模型访问计数的陈述（测试与诚实性要求）；改为在运行时就绪面板中陈述。
- 未接入 TypeSafe/Jev 等外部决策服务；引导状态全部来自本机实读的 status。

## 验证

- `gateway-setup-guide.test.mjs`：8 个场景（顺序、加载态、冷启动、缺来源、缺凭据、
  已就绪待接入、全完成、stale）。
- `model-routing-overview-layout.test.mjs`：11 个布局场景全过，含零位移与 compact 摘要断言。
- 1440/390px 真实渲染截图目视确认：引导醒目、页面明显缩短、无溢出。
- typecheck 通过。
