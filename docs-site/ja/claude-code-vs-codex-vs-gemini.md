# Claude Code vs Codex vs Gemini CLI：コーディングエージェント CLI はどれを選ぶべきか？

> **まず答え：** 5 つのコーディング CLI——Claude Code、Codex CLI、Gemini CLI、OpenCode、Hermes——はすべてファイル編集に十分な能力を持っています。日常作業で重要な違いは、モデル品質、コンテキストウィンドウ管理、エコシステムへのロックインです。どれもデフォルトではセッションをまたぐ永続的なプロジェクトメモリを備えていません。作業が複数セッション、複数エージェント、複数クライアントにまたがるなら、お気に入りの CLI をそのまま使い、その下にローカルワークフローレイヤー（AIOS）を追加してください——クライアントを置き換えずにメモリ、ルーティング、検証が加わります。

## 正直な比較

| | Claude Code | Codex CLI | Gemini CLI | OpenCode | Hermes |
| --- | --- | --- | --- | --- | --- |
| **得意分野** | 長く繊細なリファクタリング | リポジトリ規模の自動化、GitHub ネイティブ | 幅広い対応、マルチモーダル推論 | オープン、設定可能、モデル非依存 | オープンソースのリサーチエージェント |
| **モデル** | Claude | GPT-5.x 系 | Gemini | 自由に選択 | Nous Research モデル |
| **セッション間メモリ** | デフォルトではなし | デフォルトではなし | デフォルトではなし | デフォルトではなし | デフォルトではなし |
| **マルチエージェントオーケストレーション** | アドホック | 限定的 | 限定的 | プラグイン | MCP 経由 |
| **ローカルファースト** | はい | はい | はい | はい | はい |

表の「メモリ」の行が空なのが本当の話です。主要な CLI はどれもローカルファーストで編集も速い。しかしどれもデフォルトでは昨日の決定を覚えていません——まさにそれがワークフローレイヤーが埋める隙間です。

## どれを選ぶか

- **Claude Code** を選ぶのは、モデルの推論の深さが生きる、長く判断の多いリファクタリング向け。
- **Codex CLI** を選ぶのは、GitHub の中で生活し、部品を増やさずにリポジトリ規模の自動化が欲しいとき。
- **Gemini CLI** を選ぶのは、コードに加えて幅広いマルチモーダルタスクを一つのツールで扱いたいとき。
- **OpenCode** を選ぶのは、最大限の設定自由度とモデル選択の自由が欲しいとき。
- **Hermes** を選ぶのは、MCP ブリッジ面を持つオープンソースエージェントが欲しいとき。

## 欠けている行：メモリとオーケストレーション

どれを選んでも、実際にリリースされるワークフローが一回のワンショットセッションであることはまれです。実際はこうです：火曜日に決定を下し、金曜日にフォローアップし、第二のエージェントが並列レビューし、マージ前に検証ステップを踏む。5 つの CLI のどれもこれを単独で調整してはくれません。

それが AIOS が下に追加するものです：

- **ContextDB** — 5 つのクライアントすべて（と grok）で同じように動く、セッション間プロジェクトメモリ。
- **Workflow Policy** — `direct` / `guarded` / `planned` のルーティングで、プロセスの量をリスクに合わせる。
- **Agent Team** — 並列エージェントを扇出し、その証拠をマージする。
- **Solo Harness** — 検証ゲート付きで再開可能な長時間実行。

選んだクライアントはそのままです。レイヤーはどのクライアントでも同じ。詳細は [CLI 比較](https://cli.rexai.top/ja/cli-comparison/) を参照してください。

## FAQ

**2026 年で最高のコーディング CLI はどれですか？**
単一の「最高」はありません——モデル嗜好とエコシステム次第です。5 つすべて実運用に耐えます。差がつくのはメモリとオーケストレーションで、どれもデフォルトでは提供しません。

**同じプロジェクトで 2 つのコーディング CLI を使えますか？**
はい。AIOS はクライアント非依存です。同じプロジェクトでは同じ `.aios/context-db/` メモリを codex、claude、gemini、opencode、hermes、grok が共有できます。

**AIOS を使うには Claude Code から移行しないといけませんか？**
いいえ。AIOS はクライアントの下のレイヤーであり、置き換えではありません。Claude Code（または他）をそのままにして、メモリ、ルーティング、検証を追加するだけです。
