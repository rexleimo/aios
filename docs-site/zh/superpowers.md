# Superpowers 超能力

Superpowers 是可复用的技能，用于自动化常见工作流。它们接入 Claude Code、Codex、Gemini CLI 和 OpenCode 来自动处理重复任务。

不用再重复输入相同的命令或提示，只需调用一个技能，它会引导 AI 完成经过验证的工作流、强制执行最佳实践，并在完成前验证结果。
