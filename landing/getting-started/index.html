快速安装

快速上手

30 秒，让 Agent 真正把活干完。

安装 AIOS，运行 aios init --all，然后用一句话交代复杂任务。你不换客户端、不改工作方式——记忆、验证与协作都加在下面。

Node.js 24 LTS · Git · 支持 Codex / Claude Code / Gemini CLI / OpenCode / Hermes / Grok

第 1 步 · 安装

一条命令装好。

推荐用发布安装脚本；只在确实需要未发布源码时才 clone 仓库。macOS / Linux 与 Windows 各一条命令。

curl -fsSL https://github.com/rexleimo/aios/releases/latest/download/aios-install.sh | bash

Windows PowerShell：irm https://github.com/rexleimo/aios/releases/latest/download/aios-install.ps1 | iex，然后 . $PROFILE。

# 检查 Node.js 版本
node -v   # 需要 v24 LTS
npm -v

第 2 步 · 初始化项目

在项目根目录跑一次。

aios init --all 写入项目标记、同步仓库里已有的客户端指令。重复运行是安全的，不会破坏你的配置。

# 在项目根目录
aios init --all
aios doctor --native --verbose   # 立刻体检

# 无人值守：把外部权限写清楚
node scripts/aios.mjs init --all --yes-compression-tools --yes-headroom-mcp
# --dry-run 只预览，不下载、不写客户端配置

第 3 步 · 启动客户端

照你原来的方式打开。

在同一个项目目录里启动任一支持的客户端。客户端通过项目注册表按需取指令和记忆，不需要你手动搬运上下文。

codex
# 或：claude / gemini / opencode / hermes / grok

第 4 步 · 验证

看真实检查，不看装饰。

启动客户端后再跑一次 doctor，确认记忆、客户端同步与安全检查都通过；警告不等于某条路由真的能用，要跑一个小任务并保留输出。

aios doctor --native --verbose
ls .aios/context-db/
