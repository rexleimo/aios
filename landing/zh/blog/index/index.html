FAQ

想看记忆系统相关内容，先读哪篇？

如果关心 prompt 预算，先看 ContextDB Token 压缩；如果关心检索，再看 ContextDB 检索升级：FTS5/BM25 + 增量索引同步（P1.5），最后回到官方文档 /contextdb/。

想看单 Agent 夜跑，先读哪篇？

先看 Solo Harness：让一个 Agent 过夜跑，但你依然可控，再回到官方文档 单 Agent 夜跑。

Agent Team 和子代理编排更新看哪里？

重点看 Orchestrate Live：Subagent Runtime 正式可用。

AIOS 是新的 coding agent 吗？

不是。它是一个本地优先的能力层，给你正在用的 codex / claude / gemini / opencode 加上记忆、协作和验证能力——不换工具，不改习惯。
