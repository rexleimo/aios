AIOS — Local-First Graph Engine

A local-first Graph Engine for coding agents: project memory, adaptive routing, multi-agent teams, and verification on top of ten coding clients.

LOCAL-FIRST GRAPH ENGINE · v{{ aios_version }}

AIOS is a local-first Graph Engine for coding agents. It composes cross-session project memory, adaptive routing, multi-agent collaboration, and verification into a verifiable graph on top of ten coding clients — Codex, Claude Code, Gemini CLI, OpenCode, Hermes, Grok, WorkBuddy, Pi, ZCode, and Qoder — without changing how you work.

MULTI-AGENT TEAMS

Say it once. Multiple agents handle it in parallel.

One sentence from you, and AIOS splits the work across multiple agents automatically. Independent tasks run in parallel, coupled changes stay in order — you just wait for the result.

VERIFICATION / PRIVACY

It checks its own work before showing you

AIOS runs self-diagnostics, safety gates, engineering-standard gates, and verification loops on every change — so you see a working result, not a broken draft. Code-producing paths now carry a shared engineering baseline (module boundaries, file granularity, naming) with a Definition of Done that gates completion. Your code and data never leave your machine.

HOW IT WORKS

One sentence triggers four systems

Memory, routing, collaboration, and safety — all working behind the scenes.

Remembers everything

Your project decisions, constraints, and progress are saved locally. Next session, the agent picks up where it left off — no re-explaining needed.

aios init

Picks the right approach

AIOS automatically chooses the simplest path for your task — quick answer, careful edit, or full plan — so you don't have to think about process.

aios work

Splits work automatically

When your task has independent parts, AIOS runs them in parallel with multiple agents — you just say what you want once.

aios team

Checks before delivery

Safety gates and verification loops run on every change. You get a working result, not a broken draft that needs fixing.

aios verify
