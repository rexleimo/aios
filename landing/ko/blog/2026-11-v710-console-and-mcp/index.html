v7.1.0: Console 통합과 MCP 설정 공통화

로컬 AI 도구 관리 화면이 기존 Console을 대체합니다. MCP 변경은 쓰기 전에 계산하고 과거 설정 검증과 현재 연결 테스트를 구분합니다.

← 全部文章 · 首页

기본 Console이 승인된 로컬 AI 도구 관리 화면으로 바뀌었습니다. 도구, MCP 서비스, 프로젝트 메모리, 활동 기록, 설정을 하나의 화면 구성에서 다룹니다. 기존 사이드바와 페이지 구현은 삭제했으며, 이전 북마크는 대응하는 현재 화면으로 이동합니다. 새로 고침과 브라우저 뒤로 가기·앞으로 가기도 지원합니다.

새 화면은 계속해서 명확히 표시된 예제 데이터와 모의 결과를 사용합니다. 실제 비공개 프로젝트의 메모리 읽기와 설정 쓰기는 아직 연결되지 않았습니다. 기존 API, CLI, 설정, 메모리 및 세션 저장소는 유지합니다. 예제를 보는 것으로 실제 연결 성공을 증명할 수는 없습니다.

실제 MCP 설정 관리는 공통 계획기와 형식별 쓰기 모듈을 사용합니다. 한 파일의 변경을 모두 계산한 뒤 한 번의 원자적 쓰기를 수행하여 관리 대상 밖의 바이트와 클라이언트별 필드 규칙을 보존합니다. Browser, codemap, Pi, Headroom 등록이 이 경로를 재사용합니다. 내용이 일치해도 외부 항목의 소유권을 자동으로 가져오지 않으며, force도 명시적 인수를 생략할 수 없습니다.

증거 수집 도구는 기본적으로 미리 보기만 수행합니다. 명시적으로 실행하면 설정 다시 읽기, 소유권, 원래 파일 해시 복원을 확인합니다. 기록된18개 설정 위치는 검증 완료12개, 미검증1개, 현재 호스트에서 지원되지 않는5개입니다. 과거 설정 검증과 현재 연결 테스트는 별도 사실이며, 사용할 수 없는 클라이언트를 검증 완료로 보고하지 않습니다.

Console 타입 검사와 프로덕션 빌드, Shell 테스트95개가 통과했습니다. 기본 임시 환경의 최종 회귀 테스트 결과는 통과2746개, 실패0개, 건너뜀12개입니다. 브라우저 검증은 화면 이동, 메모리와 MCP 예제 흐름, 모바일 표시를 포함했으며 실제 쓰기 요청은 없었습니다. Windows TUI의 App 모듈 참조도 올바른 같은 디렉터리 경로로 수정했습니다.

이번 커밋은7.1.0버전 정보와 문서를 준비합니다. 릴리스 태그를 만들거나 설치용 패키지를 게시하지는 않습니다.
